# engelman227

Список русскоязычных телеканалов для IPTV-плеера. Он собирается каждый день из открытых списков
[iptv-org](https://github.com/iptv-org/iptv): каналы России и каналы на русском языке.

Ссылка для плеера:

```
https://raw.githubusercontent.com/do6pbiu1337-sudo/engelman227/main/playlist.m3u
```

## Что в нём

- Только каналы на русском языке.
- Без категорий «религия» (Religious) и «магазины» (Shop).
- Одинаковые каналы склеены: у канала идут подряд все его ссылки, сначала рабочие и в лучшем качестве.
- Убраны только явно мёртвые ссылки (сервер не существует, ошибка 404/410).

Если канал не показывает, а у него есть ещё ссылки, в OTT Navigator в окне ошибки выберите
«Переключиться на следующий канал»: следующая строка с тем же названием — это запасная ссылка.
Сам плеер (бесплатная версия) на запасную ссылку не переключается, это проверено.

## Только свои каналы, по-русски

В список попадают только каналы из `CHANNELS` в `build_playlist.py` (пакет каналов владельца), под русскими
названиями оттуда же. Добавить канал: дописать строку `"id-из-iptv-org": "Название"`.

## Проверка из России

Серверы GitHub за границей не отличают гео-блокировку от мёртвой ссылки. Поэтому раз в месяц на домашнем
компьютере запускают:

```
python build_playlist.py --check-from-here
```

Ссылки, которые не отвечают из России, записываются в `dead_in_russia.txt`, и ежедневная сборка их выкидывает.
Файл надо отправить на GitHub (commit + push).

## Телепрограмма

В начале списка стоит `url-tvg="http://epg.one/epg.xml.gz"`: бесплатная телепрограмма по московскому времени.
Плеер находит каналы по `tvg-name`; если в epg.one канал назван иначе, это задаёт `EPG_NAMES`.

## Категории

Девять русских категорий: Общие, Кино и сериалы, Детские, Спорт, Новости, Музыка, Познавательные,
Развлечения, Разное. Каждый канал лежит ровно в одной. Какая категория iptv-org куда попадает, задаёт
`CATEGORIES` в `build_playlist.py`.

## Как поменять фильтр

В `build_playlist.py` строка `EXCLUDED_GROUPS = {"Religious", "Shop"}`: туда можно добавить ещё
категории, например `"Kids"` или `"Sports"`. Названия категорий видно в плеере и в `playlist.m3u`
(`group-title`).

## Как обновляется

`.github/workflows/update.yml` запускается каждый день в 05:00 по Москве и сохраняет новый
`playlist.m3u`. Вручную: вкладка Actions → update → Run workflow.

В `updated.txt` записаны дата последней сборки и сколько каналов вышло. Этот файл меняется при каждом
запуске, поэтому коммит бывает каждый день: GitHub выключает расписание в открытом репозитории, если
60 дней не было никаких изменений.

Сами каналы и ссылки принадлежат их владельцам; здесь только собраны общедоступные ссылки из iptv-org.
